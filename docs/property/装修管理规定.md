# 装修管理规定

## 装修备案流程

1. **提交材料：** 业主携带以下材料到物业服务中心办理《装修备案登记》：
   - 业主身份证和房产证（或购房合同）原件及复印件
   - 装修公司营业执照、资质证书复印件（加盖公章）
   - 装修方案和全套施工图纸（含原始平面图、改造平面图、水电路改造图、天花布置图）
   - 施工负责人身份证复印件及联系电话
2. **方案审核：** 物业工程部在 3 个工作日内完成审核，重点核查是否涉及承重结构改动、消防设施改动、外立面改动等
3. **签订协议：** 审核通过后签订《装修管理协议》，明确双方权利义务
4. **缴纳押金：** 住宅装修保证金 2000 元，商业用房 5000 元
5. **领取证件：** 领取《装修许可证》，张贴于入户门内侧，备查

## 装修禁止事项

1. **严禁拆除、改动承重墙、剪力墙、配重墙、梁、柱等承重结构**
2. 严禁改变房屋原有外立面（包括封阳台、改窗户大小、改变外墙颜色等）
3. 严禁改动燃气管道、燃气表位置（如有需要须由燃气公司专业人员操作）
4. 严禁将无防水要求的房间改为卫生间、厨房
5. 严禁擅自改动消防设施（喷淋头、烟感器、消火栓等）
6. 严禁擅自在楼板、墙体上开槽打孔超过规定深度
7. 严禁将厨房烟道、卫生间排气道封堵或改变用途
8. 严禁将空调外机安装在外立面非指定位置

## 施工时间

| 时段 | 施工要求 |
|------|---------|
| 周一至周五 8:00-12:00 | 可进行所有施工 |
| 周一至周五 12:00-14:00 | 禁止噪音施工（可进行无噪音作业） |
| 周一至周五 14:00-18:00 | 可进行所有施工 |
| 周六、周日 | 禁止噪音施工 |
| 法定节假日 | 禁止一切施工 |
| 夜间（18:00-次日 8:00） | 禁止一切施工 |

## 装修垃圾处理

1. 装修产生的建筑垃圾须袋装化处理，严禁散装堆放
2. 自行清运至小区西北角 5 号楼旁建筑垃圾临时堆放点
3. 严禁将建筑垃圾堆放于楼道、绿化带、道路等公共区域
4. 严禁将建筑垃圾倒入生活垃圾桶或下水管道
5. 物业可推荐有资质的清运公司（费用由业主自行承担，参考价：600-1000 元/车）

## 施工人员管理

1. 施工人员凭《施工人员出入证》进出小区，一人一证
2. 出入证由装修公司或业主到物业服务中心统一办理，每证押金 20 元
3. 施工人员不得在小区内留宿，不得在施工单元外活动
4. 施工人员须遵守小区各项管理规定，违者物业有权取消其出入资格

## 竣工验收与押金退还

1. 装修完工后，业主联系物业管家预约验收（提前 3 天预约）
2. 验收内容：是否违规拆改承重结构、公共设施是否完好、建筑垃圾是否清理完毕、水电改造是否符合安全规范
3. 验收合格后，填写《装修竣工验收单》
4. 押金在验收合格后 15 个工作日内全额退还（原路退回）
5. 如有违规行为，按《装修管理协议》扣罚：
   - 损坏公共设施：按维修成本 1.5 倍扣罚
   - 违规拆改承重结构：全额扣罚押金，并上报住建部门
   - 建筑垃圾未清理：扣罚 300-500 元清理费

## 空调安装规定

1. 空调外机须安装在建筑设计指定的空调机位，不得安装在外立面其他位置
2. 空调冷凝水管须接入专用排水立管，不得散排至外墙或楼下
3. 安装空调需提前一天向物业报备，由物业安排安保人员引导安装人员通行
4. 空调安装产生的垃圾由安装人员自行清运
