# 应急处理指南

## 火警

1. 发现火情，立即拨打 119 并通知物业 24 小时值班电话 0571-8888YYYY
2. 若火势较小，可用灭火器或消火栓扑救（楼道每层配有 2 具灭火器和 1 个消火栓）
3. 若火势较大，立即撤离。用湿毛巾捂住口鼻，弯腰沿疏散通道迅速撤离，切勿乘坐电梯
4. 疏散集合点：小区中心花园广场
5. 物业每年 11 月组织消防演练，请积极参与

## 燃气泄漏

1. 闻到燃气味，立即关闭户内燃气总阀
2. 打开门窗通风，严禁开关任何电器（包括电灯、排气扇、门铃），严禁使用明火
3. 撤离到室外安全位置，拨打燃气公司抢修电话 95158
4. 通知物业，物业将协助疏散楼上楼下邻居
5. 每年请燃气公司上门安检一次（免费）

## 电梯困人

1. 保持冷静，切勿扒门、蹦跳
2. 按下电梯内紧急呼叫按钮（直连物业中控室）
3. 如按钮失效，拨打轿厢内张贴的维保电话
4. 电梯维保人员将在 30 分钟内到达实施救援
5. 切勿尝试自行爬出电梯轿厢

## 停电停水

### 计划性停水停电
- 物业提前 24 小时发布通知（小程序、公告栏、业主微信群）
- 请提前储备必要的生活用水
- 停电前关闭大功率电器，拔掉敏感电器插头

### 突发停水停电
- 联系物业确认故障范围和预计恢复时间
- 如为供电/供水公司原因，物业协助催办
- 如停水超过 4 小时，物业协调应急供水车

## 水管爆裂

1. 立即关闭户内总水阀
2. 用毛巾、拖把等防止水蔓延到其他房间
3. 拨打物业 24 小时值班电话
4. 如无法关闭水阀，物业可从楼栋管道井关闭户内总阀
5. 如漏水已影响楼下住户，及时通知楼下邻居

## 台风暴雨

1. 台风来临前，关闭门窗，固定或收回阳台花盆、杂物
2. 将车辆移至安全位置，避免停在大树下或低洼地带
3. 暴雨期间尽量减少外出，注意避开积水路段
4. 如发现小区内树木倾倒、外墙脱落等险情，立即通知物业
5. 地下车库如出现进水迹象，物业将通知车主移车

## 突发卫生事件

1. 如小区出现传染病疫情，物业将按卫生部门要求启动应急预案
2. 配合做好人员信息登记、体温检测、消毒消杀等工作
3. 如需居家隔离，物业可协助提供生活物资代购服务
4. 不信谣不传谣，以政府和物业官方通知为准
