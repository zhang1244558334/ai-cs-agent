# 投诉与纠纷处理

## 投诉渠道

1. **物业投诉电话：** 0571-8888ZZZZ（工作时间 8:30-17:30）
2. **物业小程序：** "投诉建议"模块，可匿名提交，3 个工作日内回复
3. **意见箱：** 物业服务中心前台设有意见箱，每周一开箱
4. **业主委员会：** 业委会办公室位于 3 号楼三楼，每月第一个周六上午 9:00-11:00 开放接待

## 投诉处理流程

1. **受理：** 物业接到投诉后 24 小时内登记受理，生成投诉工单号
2. **调查：** 物业管家在两个工作日内调查核实情况，约谈相关方
3. **反馈：** 3 个工作日内向投诉人反馈调查结果和处理方案
4. **回访：** 处理完成后 7 日内进行满意度回访

## 投诉升级

对物业处理结果不满意的，可逐级向上反映：
1. 业主委员会（受理物业不作为、服务质量等投诉）
2. 社区居委会（受理邻里纠纷调解）
3. 街道办事处物业科（受理物业管理违规问题）
4. XX区住房和城乡建设局物业管理科（受理重大物业纠纷）
5. 12345 政务服务热线

## 常见纠纷处理

### 噪音纠纷
- 邻里噪音：先友好沟通 → 无效则联系物业管家上门调解（9:00-21:00）
- 深夜严重扰民：物业协助报警（110），由公安机关依法处理
- 装修噪音：按《装修管理规定》处理，违规施工物业有权断电

### 漏水纠纷
- 楼上漏水到楼下：保护现场、拍照取证 → 联系楼上业主配合检查 → 协商维修赔偿
- 协商不成：物业可出具漏水情况说明 → 社区调解 → 诉讼
- 公共管道漏水：物业负责维修

### 侵占公共区域
- 楼道堆放杂物：物业张贴限期清理通知（7 天） → 逾期未清理由物业统一清运
- 占用绿地种菜、私搭乱建：物业下发《整改通知书》 → 上报城管部门

### 物业不作为
- 收集证据（照片、视频、聊天记录）
- 向业委会书面投诉
- 如为物业服务合同约定的服务标准不达标，可要求减免相应物业费
