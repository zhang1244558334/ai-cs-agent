# 搬家与迁入迁出指南

## 搬入流程

1. **提前报备：** 搬家前至少提前 1 天到物业服务中心或通过小程序报备，告知搬家日期、时间段、搬家车辆信息
2. **电梯预约：** 物业为您预约搬家专用电梯，铺设电梯保护垫，确保搬运过程中不损坏电梯
3. **车辆停放：** 搬家车辆在物业指定位置（各单元门口卸货区）停放，卸完即走，限停 2 小时
4. **门禁办理：** 入住后及时办理门禁卡/人脸录入，更新业主联系方式
5. **信息登记：** 在物业服务中心填写入住信息表，便于后续物业服务和紧急联系

## 搬出流程

1. **提前报备：** 同搬入，提前 1 天报备
2. **费用结清：** 搬出前须结清所有欠费（物业费、停车费、公摊水电费等）
3. **门禁注销：** 到物业服务中心退还所有门禁卡，注销人脸信息
4. **物品放行：** 搬出大件家具、家电等物品，须填写《大件物品放行单》，物业安保核对后放行（此项为防止盗窃）
5. **装修押金退还：** 如曾在入住期间装修，确认押金退还状态

## 租户迁入

1. 租户办理入住需提供：租赁合同原件及复印件、租户身份证复印件、房东书面授权书
2. 租户办理门禁卡由房东授权，门禁卡数量不得超过房东持有的数量
3. 租户有效期为租赁合同截止日期，到期后门禁权限自动失效
4. 租户联系方式需登记在册，便于紧急情况联系
5. 租户退租时须与房东共同到物业办理交接手续

## 注意事项

1. 搬家过程中注意保护公共设施（墙面、电梯、楼道），如有损坏需照价赔偿
2. 搬家产生的废弃包装材料、旧家具等大件垃圾，自行清运至西北角垃圾堆放点，不得丢弃在楼道和垃圾桶旁
3. 搬家时段：8:00-12:00、14:00-18:00，禁止中午和夜间搬家以免扰民
4. 搬家过程中请保持单元门常闭，注意随行人员和物品安全
