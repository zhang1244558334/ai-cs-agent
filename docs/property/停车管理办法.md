# 停车管理办法

## 车位类型与收费标准

| 车位类型 | 收费标准 | 说明 |
|---------|---------|------|
| 地下产权车位 | 80 元/月（管理费） | 已购买产权，仅缴纳管理费 |
| 地下租赁车位 | 400 元/月 | 一年起租，到期前一个月续签 |
| 地面车位 | 150 元/月 | 先到先停，不固定位置 |
| 临时停车 | 首小时免费，超时 5 元/小时 | 每天封顶 40 元，禁止过夜 |

## 车辆登记

1. 业主携带身份证、行驶证、房产证（或租赁合同）到物业服务中心办理车辆登记
2. 每户最多登记两辆车辆，登记信息包括车牌号、车辆品牌型号、车身颜色、联系电话
3. 登记车辆信息发生变更（换车、卖车等），应及时到服务中心更新，避免门禁识别失败
4. 租户登记车辆需由房东出具书面授权，并与租赁合同有效期一致

## 停车规则

1. 业主车辆凭车牌识别系统自动抬杆进入，请保持车牌清洁无遮挡
2. 地面车位实行"先到先停"原则，不固定位置。停满后请自行寻找小区外围公共停车场
3. 地下车位停放在指定编号车位，不得占用他人车位或通道
4. 非机动车（电动车、自行车）停放在各单元负一楼非机动车停放区，禁止进入电梯和楼道
5. 严禁占用消防通道、消防登高面停车，违者将由物业锁车并报消防部门处理
6. 小区内限速 5 公里/小时，请减速慢行，注意行人

## 访客车辆管理

1. 访客车辆由业主提前在物业小程序"访客登记"中录入车牌号，系统自动授权当日通行
2. 未提前登记的访客车辆需在门岗处由业主电话确认后登记放行
3. 访客车辆从西门进出，东门仅供业主车辆通行
4. 访客车辆不得在小区内过夜（凌晨 0:00-6:00），如需过夜须提前到物业服务中心报备，按天缴纳停车费
5. 搬家、送货等大型车辆需提前一天报备，由物业安排专用通道和临时停放位置

## 车辆安全

1. 物业收取的车位使用费/管理费为场地使用及秩序维护费用，不包含车辆保管责任
2. 建议车主购买车辆损失险和盗抢险
3. 车辆停放后请确认门窗关闭、贵重物品随身携带
4. 车辆在小区内发生刮蹭、碰撞等事故，第一时间通知物业安保调取监控，同时拨打 122 报警
5. 监控录像覆盖主要通道和出入口，保存期为 30 天。调取监控需填写《监控查阅申请单》

## 电动车充电管理

1. 电动自行车充电桩位于每栋楼负一楼非机动车停放区，扫码充电，1 元/4 小时
2. 严禁电动自行车进入电梯、楼道、室内充电，违者将上报消防部门处理
3. 电动汽车充电桩位于地下车库 B2 层东区（共 20 个慢充桩），电价按居民用电标准 + 0.2 元/度服务费，可通过物业小程序扫码充电
