# XX花园小区业主手册

## 小区概况

XX花园小区位于杭州市西湖区，总建筑面积 28 万平方米，共 12 栋住宅楼（含 3 栋高层、6 栋小高层、3 栋多层），总户数 1860 户。小区绿化率 38%，配备地下车库、儿童游乐区、健身步道、篮球场、业主活动中心等公共设施。

## 物业服务

本小区由 XX 物业服务有限公司提供物业管理服务，资质等级为一级。物业服务中心位于 3 号楼一楼西侧。

**工作时间：** 周一至周日 8:30-17:30（法定节假日安排值班人员）

**联系电话：**

- 24小时应急：0571-8888YYYY（仅限紧急报修和突发事件）
- 投诉建议：0571-8888ZZZZ

**物业服务内容：**
1. 公共区域的清洁卫生、绿化养护、秩序维护
2. 共用设施设备（电梯、水泵、消防、安防等）的日常运行、维修养护
3. 公共区域的水电费用代收代缴
4. 业主报修受理及维修协调
5. 社区文化活动的组织
6. 其他物业服务合同约定的服务事项

## 业主权利与义务

**业主享有以下权利：**
1. 按照物业服务合同的约定，接受物业服务企业提供的服务
2. 提议召开业主大会会议，就物业管理的有关事项提出建议
3. 参加业主大会会议，行使投票权
4. 选举业主委员会成员，并享有被选举权
5. 监督业主委员会的工作和物业服务企业履行物业服务合同
6. 对物业共用部位、共用设施设备和相关场地使用情况享有知情权和监督权
7. 监督住宅专项维修资金的管理和使用

**业主应履行以下义务：**
1. 遵守管理规约、业主大会议事规则
2. 遵守物业管理区域内物业共用部位和共用设施设备的使用、公共秩序和环境卫生的维护等方面的规章制度
3. 执行业主大会的决定和业主大会授权业主委员会作出的决定
4. 按照国家有关规定交纳住宅专项维修资金
5. 按时足额交纳物业服务费用
6. 法律、法规规定的其他义务

## 住宅专项维修资金

住宅专项维修资金由业主在办理房屋入住手续前按建筑面积一次性交存，标准为 50 元/平方米。维修资金属于全体业主共有，专项用于住宅共用部位、共用设施设备保修期满后的维修和更新、改造。使用维修资金需经专有部分面积占比三分之二以上且人数占比三分之二以上的业主参与表决，并经参与表决专有部分面积过半且人数过半的业主同意。

## 文明公约

1. 自觉维护小区环境卫生，不随地吐痰、乱扔垃圾，垃圾分类投放至指定垃圾桶
2. 爱护公共设施和绿化，不践踏草坪、攀折花木，不占用公共绿地种菜
3. 机动车、非机动车按规定位置停放，不占用消防通道和他人车位
4. 邻里之间和睦相处，互帮互助，发生纠纷时友好协商解决
5. 控制生活噪音，避免影响他人正常生活。夜间 22:00 至次日 6:00 禁止进行产生噪音的活动
6. 禁止在小区内从事违法违规活动，禁止擅自改变房屋用途从事经营活动
