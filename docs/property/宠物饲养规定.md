# 宠物饲养规定

## 犬只管理

根据《XX市养犬管理条例》及小区管理规约，制定本规定：

### 准养与禁养
- 每户限养一只犬（导盲犬、助残犬除外）
- 禁止饲养大型犬（肩高超过 45cm）、烈性犬。禁养品种包括但不限于：藏獒、比特犬、德国牧羊犬、杜宾犬、罗威纳犬、日本土佐犬、阿根廷杜高犬等
- 饲养犬只需取得《养犬登记证》和《犬类免疫证》，两证齐全方可在小区内饲养

### 遛犬规定
1. 遛犬时间：6:00-8:00、18:00-22:00（避开老人儿童集中活动时段）
2. 必须使用长度不超过 1.5 米的牵引绳，不得散放
3. 携犬乘坐电梯时，应为犬只佩戴嘴套，或将犬只抱离地面
4. 遛犬路线：沿小区主干道内侧行走，不得进入儿童游乐区、健身区、篮球场
5. 犬只排泄物由饲养人立即清理，物业在主干道旁设有宠物便袋箱

### 违规处理
- 未办理犬证的，物业上报城市管理部门，配合查处
- 违规饲养禁养犬的，限期 7 日内迁出小区
- 遛犬不牵绳的，劝阻无效的上报城管部门，可处 50-200 元罚款
- 犬只伤人，饲养人承担全部法律责任和赔偿
- 犬吠扰民经多次投诉不改的，物业有权要求饲养人将犬只迁出

## 其他宠物

- 饲养猫、兔、仓鼠、鸟类等宠物，须确保不影响邻居正常生活
- 宠物不得散养在公共区域
- 宠物笼具、排泄物等须妥善处理，不得污染公共环境
- 饲养特殊宠物（蛇、蜥蜴等爬行类）须提前向物业报备

## 流浪动物

- 物业不负责流浪动物的收容和喂养
- 请勿在公共区域投喂流浪猫狗，以免滋生跳蚤、传播疾病、影响环境卫生
- 如发现流浪动物，请通知物业联系动物收容机构处理
