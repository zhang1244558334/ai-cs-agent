# 特殊场景FAQ

## 大促（618/双11/双12）

**Q: 618/双11价格保护规则是什么？大促期间降价了能退差价吗？**
A: 大促期间部分商品标有"30天价保"或"全程价保"标识，购买后若商品降价可在价保期内申请退还差价。但大促期间使用的平台红包、品类券等优惠不计入价保计算范围。具体规则以活动页面"价保说明"为准。

**Q: 预售商品付了定金，不想要了定金能退吗？**
A: 支付定金后如未在规定时间内支付尾款，定金不予退还。如因商家原因（缺货等）导致交易无法完成，定金全额退还并赔偿同等金额。建议支付尾款后申请全额退款（可退回定金+尾款）。

**Q: 预售尾款怎么支付？错过尾款时间怎么办？**
A: 尾款在"我的订单-待付款"中查看支付。错过支付时间则订单自动关闭，定金不退。建议设置闹钟提醒，在尾款支付开始后尽快完成支付。

**Q: 大促期间物流会比平时慢吗？**
A: 大促期间物流会有明显延迟，预计发货时间可能从平日的48小时延长至3-5天。建议非急需商品错峰购买，使用自营物流相对更有保障。

**Q: 大促期间退款会延迟吗？**
A: 退款审核时间可能从平时的1-3天延长至3-7天。大促订单如不急需，可等大促高峰过后再集中处理退款。

**Q: 大促凑单的商品可以单独退吗？**
A: 满减凑单的商品可退货，但退款后如不满足满减门槛，优惠会失效。频繁凑单退款可能触发平台风控，建议按需购买。

**Q: 双11/618买贵了能申请保价吗？**
A: 进入"客户服务-价格保护"申请，系统自动核算差价并退款。注意保价不包含大促红包、品类券等额外优惠。

**Q: 大促期间使用白条/花呗有额外优惠吗？**
A: 大促期间通常有分期免息优惠（3期/6期/12期免息）。免息分期和大促优惠（满减、优惠券）通常可叠加使用。

## 跨境购物

**Q: 跨境购物的关税怎么算？**
A: 单次交易限值5000元，年度交易限值26000元。限值以内关税为0，增值税和消费税按70%征收。超过限值的按一般贸易全额征税。

**Q: 跨境商品退换货怎么处理？**
A: 跨境商品一般支持7天无理由退货。非质量问题的退货运费由买家承担（运费较高）。部分跨境商品不支持换货（涉及海关清关），只能退货重拍。

**Q: 跨境商品的溯源信息怎么看？**
A: 跨境电商平台的商品一般带有"溯源码"或"防伪码"，扫描可查看商品名称、原产地、物流路径、海关清关记录等。

**Q: 跨境商品在运输中损坏了怎么办？**
A: 收到后第一时间拍照取证，联系商家上传凭证。跨境商品的国际段运输损坏由国际物流承担赔偿责任。

## 礼品卡/企业采购

**Q: 礼品卡/购物卡怎么买？有使用限制吗？**
A: 京东E卡、天猫享淘卡等需绑定到个人账户使用。通常仅限自营商品或指定品类使用，不可与其他优惠重复叠加，有有效期限制。

**Q: 礼品卡可以退卡/退款吗？卡内余额能取出来吗？**
A: 已绑定的购物卡一般不支持退卡和提现，余额仅限在平台购物使用。建议按需购买，不要一次性购买大面值卡。

**Q: 企业采购流程是什么？需要什么资质？**
A: 企业用户注册企业购账号，上传营业执照认证。支持对公转账、增值税专用发票。企业采购通常有更低的价格和专属客服服务。

**Q: 对公转账（企业付款）后多久能到账？**
A: 提交订单后生成汇款识别码，通过网银或柜台汇款（备注栏填写识别码）。到账时间1-3个工作日，超期10天未到账的订单自动取消。
