## 如何正确测量

### 上衣测量
1. **肩宽**：从左肩端点水平量至右肩端点
2. **胸围**：腋下1cm处水平环绕一圈
3. **衣长**：肩颈点垂直量至下摆
4. **袖长**：肩端点量至袖口

### 裤装测量
1. **腰围**：腰部最细处水平环绕一圈
2. **臀围**：臀部最丰满处水平环绕一圈
3. **裤长**：腰头量至裤脚

### 鞋码测量
1. 赤脚站在白纸上，标记脚后跟和最长的脚趾
2. 测量两点之间的距离
3. 建议选择比脚长大0.5-1cm的鞋码

## 选码建议

- 喜欢修身效果：按实际测量尺码选择
- 喜欢宽松效果：选大一个尺码
- 介于两个尺码之间：选大不选小
