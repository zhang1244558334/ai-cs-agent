# 支付问题FAQ

**Q: 支付方式有哪些？**
A: 在线支付支持：微信支付、支付宝支付、银行卡支付。您可根据使用喜好进行选择。部分大额交易还支持企业网银和对公转账。

**Q: 支付失败了是什么原因？怎么解决？**
A: 常见原因：①银行卡余额不足或限额；②网络连接不稳定；③银行系统维护；④支付超时。建议您：①检查银行卡余额和单笔/单日限额；②切换网络重新尝试；③更换其他支付方式；④如订单已超时支付，需重新下单。

**Q: 用花呗/白条支付，怎么还款？**
A: 支付宝花呗：登录支付宝APP选择"我的-花呗"查看账单并还款，支持提前还款和分期还款。请按时还款避免产生利息和影响信用记录。

**Q: 退款到账时间是多久？**
A: 退款到支付宝余额一般为即时到账，退回银行卡需要1-7个工作日，具体受银行处理影响。原路退回的退款方式，到账时间以银行实际处理为准。

**Q: 优惠券和满减可以一起用吗？**
A: 一般情况下，平台级优惠券、店铺优惠券和满减活动在规则允许范围内可叠加使用，但同一类型的优惠（如多张店铺券）通常不能叠加。具体以结算页面展示的最终优惠为准。

**Q: 可以分期付款吗？免息吗？**
A: 支持花呗分期（3/6/12期等）和白条分期。部分商品或特定活动期间有"免息分期"优惠，在商品详情页或结算页面会有"免息"标识。具体分期费率和期数以支付页面展示为准。

**Q: 用公司账户转账付款可以吗？**
A: 支持企业网银（线上支付）和线下公司转账。企业采购可通过企业支付宝对公付款，也可联系客服处理对公转账事宜。

**Q: 为什么我付款了但订单显示未支付？**
A: 通常是银行扣款成功但支付信息未及时同步到平台。建议：①等待5-15分钟刷新订单页面；②如仍未更新，联系客服提供银行扣款截图，客服会协助处理订单状态。避免重复支付。

**Q: 商品价格保护怎么申请？价保退的钱退到哪里？**
A: 本店商品一般支持7天或30天价保（具体以商品页面标注为准）。如购买后商品降价，可联系客服申请差价退还。价保退款一般原路返回或退至账户余额。

**Q: 货到付款支持吗？**
A: 目前暂不支持货到付款，所有订单需在线支付后安排发货。

## 支付补充

**Q: 京东组合支付怎么操作？可以用余额+银行卡一起付吗？**
A: 京东支持组合支付（混合支付），即一笔订单中同时使用多种支付方式。支持的组合方式：①京东余额+银行卡；②京东余额+京东E卡；③京东E卡+银行卡；④京东白条+余额（部分场景）。操作方式：结算页面选择"组合支付"→输入各支付方式的使用金额→确认支付。注意：①组合支付暂不支持白条分期+其他方式的组合；②如果退款，按各支付方式的比例原路退回；③优惠券和组合支付可以同时使用。来源：京东支付帮助中心。

**Q: 淘宝余额（支付宝余额）+银行卡可以组合支付吗？**
A: 淘宝/支付宝支持组合支付。操作方式：在淘宝提交订单后，在支付宝收银台页面选择"组合支付"（或"分付"），分别输入支付宝余额和银行卡的扣款金额。注意：①组合支付时，支付宝余额优先使用；②优惠券在组合支付时同样适用；③跨境交易暂不支持组合支付；④退款时分别退回到各自的支付方式。来源：支付宝帮助中心。

**Q: 境外信用卡在京东/淘宝购物有手续费吗？**
A: 境外信用卡支付手续费情况：①京东：使用Visa/MasterCard/American Express等境外信用卡支付，京东不额外收取手续费，但您的发卡行可能收取货币转换费（一般1%-3%，取决于发卡行政策）；汇率以发卡行结算日的汇率为准。②淘宝/天猫国际：通过国际支付宝使用境外信用卡，支付宝收取一定的手续费（一般3%-4%，含货币转换费）。③拼多多：暂不支持境外信用卡直接支付。建议：境外卡消费前先咨询发卡行了解跨境交易手续费标准，大额消费考虑汇率波动影响。来源：京东支付-外卡支付说明。

**Q: 京东白条/支付宝花呗支付限额是多少？怎么提升？**
A: 京东白条额度：初始额度一般在¥2,000-¥10,000（根据个人信用评估），单笔支付限额与可用额度一致。花呗额度：初始额度一般在¥500-¥50,000，单笔支付限额根据商家和商品类型不同。提升额度的方法：①完善个人实名信息和信用资料；②保持良好消费和还款记录；③京东白条——购买京东金融理财产品、绑定信用卡辅助认证可提升额度；④花呗——多使用支付宝、购买余额宝、芝麻信用分提升等。临时额度：大促期间（618/双11）平台可能主动提供临时额度，请在额度页面查看。来源：京东金融帮助中心、支付宝花呗规则。

**Q: 京东/淘宝支付密码忘记了怎么办？**
A: 京东支付密码重置：进入"我的京东-账户设置-支付密码-忘记支付密码"，通过验证手机号+身份证信息重置，或通过人脸识别验证重置。淘宝支付密码（支付宝支付密码）重置：打开支付宝App→"我的-设置-密码设置-重置支付密码"，通过身份验证（人脸/短信/银行卡信息）后重新设置。注意：支付密码与登录密码不同，忘记支付密码不影响正常登录购物，但影响支付和修改账户信息。来源：京东安全中心、支付宝安全中心。

**Q: 京东白条分期的手续费是多少？提前还款有手续费吗？**
A: 京东白条分期费率（具体以支付页面为准）：①3期：0.5%-0.8%/期；②6期：0.5%-0.7%/期；③12期：0.5%-0.6%/期；④24期：0.5%-0.6%/期。大促期间常见免息分期（3期/6期免息）。提前还款：①白条支持提前还款（含提前结清）；②提前还款不收取额外手续费（仅需偿还剩余本金+已产生的利息）；③但部分分期活动可能规定提前还款需支付剩余期数的全部手续费（以活动规则为准，下单前有提示）。来源：京东金融-白条规则。

**Q: 淘宝买家可以用国际支付宝（Alipay）支付吗？有什么限制？**
A: 国际支付宝（Alipay for Cross-border Solutions）支持境外消费者在淘宝/天猫购物支付。支持的支付方式：①境外信用卡（Visa/MasterCard/JCB等）；②国际银行卡；③部分支持当地电子钱包（如Touch 'n Go eWallet马来西亚等）。限制：①单笔交易限额一般为¥5,000（跨境电商额度）；②年交易限额¥26,000（海关跨境电商限值）；③需要提供有效的国际手机号和邮箱注册；④部分商品（如食品、化妆品）可能限制跨境销售。来源：阿里巴巴国际支付帮助中心。

**Q: 淘宝/京东的亲情账号/代付功能怎么使用？**
A: 淘宝的"代付"功能：下单后在支付页面选择"找人代付"，生成代付链接/二维码，对方通过支付宝代付。代付人需是支付宝好友。京东：目前京东暂不支持直接代付功能，但可以通过以下方式替代：①将商品加入购物车后分享链接给亲友；②使用京东"礼品卡"赠送；③使用京东"帮付"（部分版本支持白条代付，通过白条额度共享）。淘宝代付注意事项：①代付后如果退款，款项退回代付人的支付账户；②代付不限制次数，但频繁代付可能触发风控。来源：淘宝帮助中心。

**Q: 京东支付限额（单笔/单日）是多少？怎么调整？**
A: 京东支付限额标准（根据支付方式不同）：①京东余额（钱包余额）：单笔¥50,000、单日¥100,000；②银行卡快捷支付：单笔¥5,000-¥50,000（发卡行决定）、单日¥5,000-¥100,000；③京东白条：不得超过可用额度（可用额度最高¥50,000）；④京东E卡：单笔不限额（卡内余额范围内）。调整方法：①银行卡额度需联系发卡行调整（拨打银行客服）；②京东余额额度可通过实名认证提升（高级认证后可提高）；③白条额度通过京东金融申请提额。大额支付建议分批支付或使用企业网银转账。来源：京东支付帮助中心。

**Q: 淘宝/京东退款到银行卡一般需要多久？不同银行有差别吗？**
A: 退款到银行卡的时效因银行不同：①国有大行（工行/建行/农行/中行/邮储）：一般1-3个工作日到账；②股份制银行（招行/浦发/中信/民生等）：一般1-2个工作日到账；③地方性银行/农商行：一般3-7个工作日到账（部分小银行处理较慢）；④支付宝余额退款（即时到账）可立即提现至银行卡。京东退款规则：①退至京东余额实时到账；②退至银行卡1-7个工作日；③京东E卡退至卡内实时。提示：退款时如选择"退至平台余额"可最快到账，后续再自行提现。来源：京东帮助中心、支付宝帮助中心。
