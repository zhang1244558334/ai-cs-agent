# 售前咨询FAQ

## 商品咨询

**Q: 这商品有现货吗？什么时候能发货？**
A: 亲，商品页面显示的"库存"数字即为当前可售数量，下单后即有库存保留。现货商品一般在您付款后48小时内安排发货，具体发货时间以商品详情页标注为准，部分定制或预售商品会有单独的发货说明。

**Q: 商品颜色和图片有色差吗？**
A: 亲，商品图片均为实物拍摄，但由于不同显示设备（手机/电脑）屏幕色彩存在差异，实物颜色可能与图片略有差别，属于正常现象，请您以实物为准。如有严重色差问题，可联系客服处理。

**Q: 怎么确认是正品？有正品保障吗？**
A: 本店所售商品均为正品行货，享受厂家全国联保服务。平台提供"假一赔四"消费者保障服务，购买带有"品牌授权"或"天猫"标识的商品享受更严格的正品保障。

**Q: 商品可以定制吗？比如刻字、定制尺寸？**
A: 部分商品支持定制服务，您可以在商品详情页查看是否有"定制"或"个性定制"选项。如有定制需求，建议在下单前先联系客服确认定制规则、工期和是否支持退换货。

**Q: 这个商品参加什么活动？有没有更优惠的价格？**
A: 商品是否参加平台大促（如618、双11、双12、百亿补贴等）会在商品详情页有明确的活动标签。您也可以关注店铺首页获取店铺专属优惠信息，价格保护期内可申请价保退款。

**Q: 买错了能换吗？还没发货能改吗？**
A: 订单未发货前，您可以在订单详情页自行修改订单信息或取消重新下单。若已发货但未签收，可在签收后申请换货。7天无理由退货商品可在签收后7天内申请退换。

## 发票

**Q: 可以开发票吗？发票金额怎么算？**
A: 本店商品均开具正规发票，发票金额含配送费金额，另有说明的除外。如需发票，下单时请勾选"需要发票"并填写发票抬头信息，发票将随商品或单独邮寄给您。

## 客服联系

**Q: 怎么联系商家客服？**
A: 您可以直接在对话框中输入问题，AI客服24小时在线。如需人工服务，请说"转人工"。人工客服工作时间：每天9:00-22:00。

## 分期付款

**Q: 商品支持分期付款吗？**
A: 支持花呗分期/白条分期，在付款页面选择对应支付方式即可查看可选期数（3期、6期、12期等）。部分商品有免息分期活动，具体以结算页面展示为准。

## 优惠券

**Q: 优惠券和满减能叠加使用吗？**
A: 一般情况下，商品级优惠（如单品优惠券）和订单级优惠（如满减、店铺券）可以叠加，但同类优惠通常不可叠加，具体以结算页面展示的优惠明细为准。最终优惠金额以提交订单时系统计算为准。

## 商品深度咨询

**Q: 这个商品的保质期到什么时候？能发近期生产的吗？**
A: 食品、化妆品等有保质期的商品，商品详情页一般会标注保质期信息。下单前如需确认具体生产日期或要求发近期生产的，请联系客服咨询。

**Q: 商品产地是哪里？是国产还是进口？**
A: 商品产地信息一般在商品详情页的参数栏中有标注。注意区分"品牌归属国"和"实际生产地"——很多国际品牌在中国设有工厂。

**Q: 这个成分/材质安全吗？有没有有害物质？**
A: 正规渠道销售的合规商品均需符合国家质量安全标准。纺织品需符合GB 18401国家纺织产品基本安全技术规范（A类婴幼儿、B类直接接触皮肤、C类非直接接触皮肤）。电子产品需有3C认证。

**Q: 这个商品有3C认证吗？**
A: 中国强制性产品认证（3C认证）覆盖电子产品、家电、玩具等品类。正规商品需通过3C认证并在页面展示认证编号。没有3C认证的强制认证产品不得在国内销售。

**Q: 不同批次的商品会有差异吗？**
A: 不同批次可能存在微小差异（食品口感、服装色差、电子产品固件版本等），在国家标准允许范围内且不影响正常使用即为合格产品。

**Q: 赠品是什么？送完即止还是什么规则？**
A: 赠品信息一般在商品主图或详情页有标注。常见规则："送完即止"、"下单即送"、"前XX名下单送"。赠品一般不单独保修，但需与页面承诺一致。

**Q: 发票抬头能修改吗？已经开了发票还能改吗？**
A: 发票未开出前可以修改。已开具的普通发票一般无法修改，需联系客服确认是否支持红冲重开。专用发票修改流程较复杂。

**Q: 这个商品适合什么人群？有什么禁忌/注意事项？**
A: 保健品会标注"适宜人群"和"不适宜人群"。化妆品需注意敏感肌慎用成分。电子产品需确认兼容性。具体请详读商品详情页或咨询客服。

**Q: 商品的保修政策是全国联保还是店铺保修？**
A: 全国联保——凭正规发票可在品牌全国任何授权售后网点享受保修。店铺保修——需联系购买店铺进行售后维修。京东自营商品一般为全国联保。

**Q: 这个商品和另一个商品有什么区别？哪个更好？**
A: 可使用商品详情页的"商品对比"功能查看规格参数差异。关注核心差异点（材质/容量/功能/保修等）。如拿不准，可咨询客服说明使用场景获取推荐。
