# 常见问题FAQ

> 以下是高频常见问题速查，详细分类请参考对应FAQ文档。

## 发货与物流

**Q: 下单后多久发货？**
A: 工作日当天16:00前下单，当天发货；16:00后下单，次日发货。周末和节假日订单顺延至工作日发货。

**Q: 发什么快递？**
A: 默认发中通快递。如需发顺丰，请联系客服补运费差价（+12元）。

**Q: 可以指定快递吗？**
A: 目前默认中通，暂不支持指定其他快递。

**Q: 如何查看物流信息？**
A: 发货后您会在订单页面看到快递单号，可在我的订单→查看物流中跟踪。

## 支付

**Q: 支持哪些支付方式？**
A: 支持支付宝、微信支付、银行卡支付。

**Q: 可以货到付款吗？**
A: 目前暂不支持货到付款。

**Q: 支持分期付款吗？**
A: 支付宝花呗支持3/6/12期分期，微信支付分也可分期。具体手续费以支付页面显示为准。

## 优惠

**Q: 有优惠券吗？**
A: 新用户关注店铺可领取10元无门槛优惠券。满200减20、满500减60优惠券可在店铺首页领取。

**Q: 参加满减活动吗？**
A: 目前全店参加满200减20、满500减60活动，部分特价商品不参与。

**Q: 有会员折扣吗？**
A: 消费满1000元自动升级为银卡会员（9.5折），满3000元升级为金卡会员（9折）。

## 商品

**Q: 商品是正品吗？**
A: 所有商品均为品牌正品，支持专柜验货，假一赔十。

**Q: 色差大吗？**
A: 图片为实物拍摄，但由于显示器差异可能存在轻微色差，属于正常现象。

**Q: 可以定制吗？**
A: 目前暂不支持定制服务。

**Q: 缺货会通知吗？**
A: 缺货商品可点击"到货提醒"，到货后系统会自动发送通知。

## 售后

**Q: 怎么联系客服？**
A: 您可以直接在对话框中输入问题，AI客服24小时在线。如需人工服务，请说"转人工"。

**Q: 客服工作时间？**
A: AI客服24小时在线。人工客服工作时间：每天9:00-22:00。
