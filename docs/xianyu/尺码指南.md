# 尺码与测量指南

## 关于尺码

个人闲置物品，尺码信息在商品描述里已标注。

**Q: 这件衣服我穿合适吗？**
A: 商品描述里有具体尺寸和测量方式。建议拿自己的衣服平铺量一下对比，比问身高体重靠谱。每个人身材比例不一样，高矮胖瘦很难判断。

**Q: 鞋子码数准不准？偏大还是偏小？**
A: 不同品牌码数会有差异，商品描述里已注明具体鞋码和鞋垫长度。建议量一下自己常穿鞋子的鞋垫长度对比。

**Q: 能不能帮我量一下具体尺寸？**
A: 可以，具体要量哪里私聊说。

## 测量方法

建议拿自己合身的同类衣服平铺测量对比：
- **肩宽**：左肩缝线到右肩缝线
- **胸围**：腋下1cm处平量 
- **衣长**：肩颈点量到下摆
- **袖长**：肩缝线量到袖口
- **腰围**：裤腰平铺量的两倍
- **裤长**：腰头量到裤脚

## 选码建议

- 拿不准的问卖家要具体数据
- 个人闲置不支持无理由退换，买前确认好尺码
- 不确定的宁可不买，别怀着侥幸心理
