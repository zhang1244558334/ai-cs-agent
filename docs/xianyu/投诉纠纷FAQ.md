# 投诉与纠纷处理

## 纠纷类型

- 收到商品与描述不符（成色、功能、破损等）
- 卖家未按约定时间发货
- 收到空包、假货、仿品
- 恶意退款、恶意差评

## 处理流程

1. 双方优先协商解决，闲鱼"聊一聊"内沟通
2. 协商不成，买/卖方可申请平台介入
3. 平台客服先行调解，大部分纠纷在此阶段解决
4. 调解失败，进入闲鱼小法庭裁决

## 闲鱼小法庭

- 双方提交证据（聊天记录、商品照片、物流单号等）
- 平台随机邀请17位高信用用户组成评审团
- 先获9票的一方胜诉
- 裁决为最终结果，不可上诉
- 胜诉方：买家退款、卖家收到款项

## 常见纠纷建议

- 商品拍照留底，发货前拍照
- 聊天记录保留完整，不删除
- 描述商品时如实说明瑕疵，不隐瞒
- 贵重物品建议发顺丰并购买保价
