# 发货与物流

## 发货时效

- 个人卖家非全职经营，发货时间可能不固定
- 一般承诺48小时内发货（建议在商品描述中注明）
- 特殊商品（大件、定制）发货时间另行协商
- 买家拍下付款后，卖家在闲鱼App内点击"去发货"即可预约快递

## 物流方式

- 默认发中通、圆通、韵达等普通快递
- 卖家可设置支持自提（当面交易）
- 大件商品走物流（德邦、安能等），运费单独协商
- 发货后在闲鱼App内填写快递单号，买家可追踪物流

## 运费说明

- 是否包邮由卖家自行设定
- 包邮商品默认运费由卖家承担
- 不包邮商品，运费以系统显示为准
- 偏远地区（新疆、西藏等）可能需要补运费差价

## 收货提醒

- 收到包裹请当面验收，有问题当场拍照留存
- 确认商品无误后，请及时在App内确认收货
- 确认收货后款项打给卖家，交易完成
