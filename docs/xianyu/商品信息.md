# 商品信息

本店为个人闲置卖家，所有商品均为自用闲置转卖，非商家批量销售。

## 关于商品来源

- 所有商品为本人自用购入，非二手贩子倒卖
- 品牌商品注明购买渠道和时间
- 仿品、山寨商品会明确标注，不卖假货

## 关于成色

- 所有商品实拍图，所见即所得
- 使用痕迹、瑕疵如实描述
- 成色描述标准：
  - **全新**：未使用，吊牌/包装齐全
  - **几乎全新**：仅拆封试用，无明显使用痕迹
  - **九成新**：正常使用，轻微痕迹
  - **八成新**：有明显使用痕迹，不影响使用
  - **七成新及以下**：多处瑕疵，功能正常

## 关于商品详情

**Q: 这个商品还在吗？**
A: 能拍就是还在，卖了会下架。不用问还在不在。

**Q: 是正品吗？**
A: 品牌商品会注明来源渠道，支持验货。如果是仿品会明确标注"非正品"。

**Q: 有没有更多细节图？**
A: 可以，需要看哪里私聊，看到了会拍给你。

**Q: 电子产品的电池/功能怎么样？**
A: 商品描述里有说明功能状态。电子产品都会测试好再上架，有问题提前说。

**Q: 包装/配件齐全吗？**
A: 商品描述里有写配件情况。个人闲置不一定保留原包装和全部配件。

**Q: 可以留货/预留吗？**
A: 不支持预留，拍下付款为准。先到先得。

## 关于议价

- 标价即心理价，可小刀，合理范围内可聊
- 屠龙刀（砍一半以上）不回
- 多件一起买可适当优惠
