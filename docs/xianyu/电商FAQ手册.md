# 闲鱼卖家手册

## 关于本店

- 个人闲置卖家，不是商家，不是二手贩子
- 商品均为自用闲置，成色如实描述
- 不支持无理由退货（个人闲置非电商，请理解）
- 有问题买前问清楚，确认好再拍

## 价格与优惠

- 个人闲置无会员体系、无优惠券、无满减
- 标价即卖价，觉得不合适可以聊一聊砍价
- 价格可小刀（合理范围内可议价）

## 关于商品

- 所有商品实拍，所见即所得
- 瑕疵、使用痕迹如实说明
- 细节问题欢迎私聊确认

## 售后说明

- 个人闲置卖出后不支持无理由退货
- 如商品与描述严重不符，可协商解决
- 协商不成走闲鱼小法庭

## 发货说明

- 一般48小时内发货
- 默认中通/圆通包邮
- 支持本地自提
- 偏远地区需补运费
