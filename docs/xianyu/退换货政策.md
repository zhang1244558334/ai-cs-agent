# 闲置物品交易须知（原退换货政策）

## 退货退款规则

- 闲鱼是个人对个人的闲置交易平台，卖家不是商家
- 根据《消费者权益保护法》，个人闲置交易不强制适用"七天无理由退货"
- 是否支持退货由卖家自行决定，建议在商品描述中明确说明
- 如卖家未明确承诺退货，平台默认不支持无理由退货
- 商品与描述严重不符、收到空包等情况，买家可申请平台介入

## 交易保障

- 所有交易必须走闲鱼担保交易，买家付款后款项由平台保管
- 买家确认收货后，款项才打给卖家
- 不私下转账、不微信转账、不支付宝转账，脱离平台的交易不受保护

## 闲鱼小法庭

- 买卖双方协商不成时，可申请闲鱼小法庭裁决
- 平台随机邀请高信用用户组成17人评审团
- 先获得9票支持的一方胜诉
- 小法庭裁决为最终结果，双方必须遵守
- 申请小法庭后一般24小时内出结果
