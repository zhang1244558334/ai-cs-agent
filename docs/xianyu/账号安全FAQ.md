# 账号安全与交易防骗

## 账号安全

**Q: 闲鱼账号被盗了怎么办？**
A: ①立即用绑定手机找回密码；②检查是否有异常发布的商品或聊天记录；③在"安全中心"解绑异常设备；④如有资金损失联系支付宝客服冻结账户。

**Q: 忘记密码/无法登录怎么办？**
A: 登录页面点击"忘记密码"，通过绑定手机号接收验证码重置。绑定手机已停用需联系闲鱼客服人工申诉。

**Q: 芝麻信用分低了影响交易吗？**
A: 芝麻信用分会在个人主页显示，分低可能影响买家信任度。建议保持良好的支付宝使用习惯提升信用分。

**Q: 账号被限制/封禁了怎么办？**
A: 常见原因：发布违禁品、频繁违规、被多人举报。可在"帮助与客服"中申诉，提供相关证据，一般3-7个工作日审核。

## 交易防骗指南

**Q: 买家让我加微信/QQ私下交易怎么办？**
A: 坚决拒绝！所有交易必须在闲鱼App内完成。脱离平台的交易不受保护，出问题没人管。遇到要求私下交易的直接举报。

**Q: 买家发来一个付款链接/二维码让我扫？**
A: 这是诈骗！闲鱼付款只在App内操作，不会有外部链接。不要点击任何外部链接，不要扫描陌生人发来的二维码。立即拉黑举报。

**Q: 买家说"已付款但没显示"，让我先发货？**
A: 骗局！以闲鱼App内订单状态为准，没有显示"买家已付款"绝不发货。任何截图都可能是伪造的。

**Q: 卖家让我先确认收货再发货？**
A: 拒绝！确认收货后钱就打给卖家了，没收到货就确认风险极大。按正常流程：付款→卖家发货→收到货验货→确认收货。

**Q: 买家要求发到货付款（COD）？**
A: 闲鱼不支持货到付款。所有交易走闲鱼担保支付，买家先付款到平台，收到货确认后卖家才能收到钱。

**Q: 遇到"平台客服"主动联系我处理纠纷？**
A: 注意辨别！闲鱼官方客服不会主动通过聊天联系你处理纠纷，更不会索要验证码、密码。怀疑是骗子直接在App内走官方投诉渠道。

**Q: 卖二手手机/贵重物品需要注意什么？**
A: ①发货前拍视频留证（包括功能演示、外观细节、序列号）；②发顺丰并购买保价；③在商品描述注明序列号防止调包；④要求买家当面验收签收。
