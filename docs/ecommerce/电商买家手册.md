# 电商平台买家手册

## 关于本平台

本店为入驻淘宝/天猫/京东/拼多多等主流电商平台的品牌商家，所有商品均为品牌正品，支持官方验货和7天无理由退换货（特殊商品除外）。

### 平台区别

| 平台 | 特点 | 客服入口 |
|------|------|---------|
| 淘宝/天猫 | 品类最全，88VIP会员体系 | 消息→联系卖家 |
| 京东 | 自营物流快，PLUS会员 | 商品页→联系客服 |
| 拼多多 | 价格优势，百亿补贴 | 商品页→客服 |
| 抖音电商 | 直播带货，兴趣推荐 | 商品页→客服 |

## 购物流程

1. **选商品** → 浏览商品详情页，查看规格、价格、评价
2. **加购物车** → 可以加多个商品一起结算
3. **下单** → 选择收货地址、支付方式、配送方式
4. **支付** → 支付宝/微信/银行卡/白条/花呗等
5. **等待发货** → 商家在承诺时效内发货
6. **确认收货** → 收到货后检查无误，点击确认收货
7. **评价** → 给出真实评价帮助其他买家

## 支付方式

- **支付宝**：淘宝/天猫默认，支持花呗分期
- **微信支付**：拼多多/京东/抖音主要方式
- **京东支付**：京东自有支付，支持白条
- **银行卡**：各平台都支持借记卡/信用卡

## 配送说明

- 发货时效以商品页面标注为准（一般24-72小时）
- 京东自营商品通常次日达，部分城市211限时达
- 天猫超市次日达覆盖主要城市
- 快递公司：京东物流/顺丰/中通/圆通/韵达/EMS等

## 价格说明

- 商品页面显示的价格为当前售价（不含运费）
- 大促期间（618/双11/双12）价格可能变动
- 部分商品支持"价格保护"，买贵了可申请退差价
- 优惠券/平台红包/满减活动可叠加使用

## 售后保障

- 7天无理由退换货（不影响二次销售）
- 部分商品不支持无理由退货（生鲜/定制/内衣等，详见商品页标注）
- 质量问题商家承担退货运费
- 非质量问题买家承担退货运费
- 各平台都有消费者保障基金，商家不处理可申请平台介入

## 客服与投诉

- 优先联系商家客服处理
- 商家48小时不处理可申请平台介入
- 淘宝/天猫：淘宝小二介入
- 京东：京东客服介入
- 拼多多：平台客服介入
- 重大纠纷可拨打12315投诉

## 安全购物提醒

- 所有交易在平台内完成，不加微信私下交易
- 不点击陌生人发来的付款链接
- 不扫描来源不明的二维码
- 平台客服不会索要验证码/密码
- 收到可疑电话挂断后在App内联系官方客服核实
