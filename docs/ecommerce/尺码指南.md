## 如何正确测量

### 上衣测量
1. **肩宽**：从左肩端点水平量至右肩端点
2. **胸围**：腋下1cm处水平环绕一圈（取最大值）
3. **衣长**：肩颈点垂直量至下摆
4. **袖长**：肩端点量至袖口

### 裤装测量
1. **腰围**：腰部最细处水平环绕一圈（放松状态，不吸气收腹）
2. **臀围**：臀部最丰满处水平环绕一圈
3. **裤长**：腰头量至裤脚

### 鞋码测量
1. 赤脚站在白纸上，标记后跟和最长脚趾
2. 量两点间距离=脚长
3. 鞋码≈脚长(cm)×2-10
4. 建议选比脚长大0.5-1cm的鞋码（脚胖/宽选大1cm）

## 选码建议

- **修身款**：按实际测量选
- **宽松款**：选大一个码
- **夹在两个码中间**：选大不选小
- **不确定时**：提供身高/体重/体型给客服帮你推荐
- **不同品牌尺码差异大**：优衣库偏大、ZARA偏小、运动品牌偏宽松——以具体商品尺码表为准
- **网购建议**：第一次在某品牌买，可以买两个尺码试穿后退一件
