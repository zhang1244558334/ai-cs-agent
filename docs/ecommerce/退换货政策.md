# 退换货政策

## 七天无理由退换货

根据《消费者权益保护法》和《网络购买商品七日无理由退货暂行办法》，通过网络购买的商品，消费者有权自收到商品之日起7日内退货，且无需说明理由。

### 适用条件

- 商品完好，不影响二次销售
- 包装、配件、赠品齐全
- 商品本身无损坏、无使用痕迹（试穿/试用除外）
- 退货时一并退回发票（如有）

### 不适用七天无理由的商品

以下商品一经售出不支持7天无理由退货：
- 消费者定做的商品（定制类）
- 鲜活易腐商品（生鲜、水果、鲜花等）
- 在线下载或拆封的数字化商品（音乐、软件、电子书）
- 交付的报纸、期刊
- 拆封后影响品质的商品（如食品、保健品、化妆品拆封后）
- 内衣裤、袜类等贴身衣物（卫生考量）
- 已激活的电子产品（手机、平板、手表等，激活后不支持无理由退货）

## 退货流程

1. **申请退货** → 在订单详情页点击"申请售后"→ 选择"退货退款"
2. **商家审核** → 商家在48小时内审核，同意后系统生成退货地址
3. **寄回商品** → 按地址寄回，填写快递单号（建议保留快递底单）
4. **商家收货** → 商家签收后验货
5. **退款** → 验货无误，1-3个工作日内退款到原支付账户

## 运费承担

| 情况 | 运费承担方 |
|------|-----------|
| 7天无理由退货（非质量原因） | 买家承担 |
| 商品质量问题 | 卖家承担 |
| 发错货/少件/破损 | 卖家承担 |
| 商品与描述不符 | 卖家承担 |
| 买家不喜欢/不想要 | 买家承担 |

## 换货

- 换货需在收货后15天内申请
- 商品有质量问题可换同款同规格商品
- 如无同款可协商换其他商品或退款
- 换货产生的运费由责任方承担

## 退款时效

- 支付宝余额/花呗支付：即时到账（退款成功后秒到）
- 银行卡/信用卡：1-3个工作日
- 微信支付：即时到账
- 白条：即时恢复额度
- 京豆/金币/积分：退回账户

## 注意事项

- 退换货前建议拍照留证（商品状况、包装、快递面单）
- 贵重商品建议购买运费险（淘宝运费险、京东退换无忧）
- 保留与商家的聊天记录作为证据
- 如商家拒绝合理退货，可申请平台介入
- 超过15天的订单，如有质量问题仍可协商处理（质保期内）
