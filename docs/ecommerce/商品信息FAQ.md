# 商品信息FAQ

## 商品来源

本店商品均为品牌正品，从品牌方/官方授权经销商渠道进货，支持官方验货和7天无理由退换货（特殊商品除外）。

## 常见商品咨询

**Q: 商品的保质期/生产日期是多久？**
A: 食品/化妆品/保健品有保质期要求，发货时保证剩余保质期≥1/3（进口商品≥1/5）。具体批次的生产日期在商品包装上。有特殊要求可备注或联系客服。

**Q: 商品的SN码/序列号在哪里？**
A: 电子产品SN码一般在：产品包装盒侧面/背面、机身底部/背面、系统设置→关于本机中。凭SN码可在品牌官网查询激活日期和保修状态。

**Q: 有没有防伪码？怎么验证？**
A: 品牌商品包装上有防伪标签，刮开涂层获取防伪码，在品牌官网或400电话验证。进口商品部分有CIQ溯源码。

**Q: 商品包装是原装吗？有无瑕疵？**
A: 所有商品均为原装正品包装。快递运输可能造成外包装轻微挤压，不影响商品使用。如对包装有特殊要求（送礼），建议备注或联系客服。

## 商品参数说明

| 品类 | 关键参数 | 怎么看 |
|:----|:--------|:------|
| 手机 | 芯片/存储/屏幕 | 芯片决定性能，存储决定能存多少东西，屏幕决定显示效果 |
| 电脑 | CPU/显卡/内存/硬盘 | CPU和显卡决定跑多快，内存决定能同时开多少程序 |
| 家电 | 功率/能效/尺寸 | 功率影响电费，能效越高越省电，尺寸决定放不放得下 |
| 服装 | 面料/版型/尺码 | 棉麻亲肤但易皱，化纤耐穿但透气差，混纺取中间 |
| 食品 | 配料/净含量/保质期 | 配料表越短越健康，食品添加剂在国标内是安全的 |

## 商品对比

**Q: 这款和另一款有什么区别？**
A: 可对比页面上的参数表，主要看价格差异对应的配置差异。一般来说：同品牌货比规格，不同品牌货比口碑和售后。

**Q: 新品和旧款怎么选？**
A: 新品功能新但价格高，旧款性价比高但可能停产。数码产品建议买新不买旧（旧款很快被淘汰）。家电/日用品买旧款即可，功能差异不大。

## 缺货与下架

**Q: 商品显示无货/已下架，什么时候补货？**
A: 无货商品可点击"到货通知"，到货后短信/App推送。下架商品通常不再补货（停产/换季/合约到期），建议找替代品。

**Q: 缺货时可以先下单等发货吗？**
A: 部分商品支持"缺货预订"，页面有"预售"或"采购中"标识，标注预计发货时间。无预售标识的商品不支持预订。
