# 订单与物流FAQ

## 下单

**Q: 下单后多久发货？**
A: 不同商家发货时效不同，商品详情页一般有标注：
- 现货：24-72小时内发货
- 预售：按页面标注发货时间（通常7-30天）
- 京东自营：当天发（11点前下单）/次日发
- 天猫超市：当天发（16点前下单）/次日达

**Q: 下单后可以修改地址吗？**
A: 未发货→联系客服修改。已发货→无法修改，可联系快递公司拦截或转寄（可能产生费用）。大促期间修改地址可能导致发货延迟。

**Q: 下单后可以取消吗？**
A: 未付款→24小时自动取消。已付款未发货→申请退款秒到账。已发货→需拒收或收到后退货退款。

## 物流

**Q: 发什么快递？**
A: 淘宝/天猫：中通/圆通/韵达/邮政为主，大件走德邦/安能。京东自营：京东物流为主。拼多多：各家快递随机，系统分配。具体以商家设置为准。

**Q: 快递到哪了？怎么查物流？**
A: 订单详情→查看物流，可看到实时轨迹。也可在快递公司官网/菜鸟裹裹输入快递单号查询。

**Q: 物流好几天不更新了怎么办？**
A: 联系商家客服查询物流状态。如确认丢件：商家补发或退款。大促/恶劣天气期间物流延迟属正常现象。

**Q: 收到空包/少件/破损怎么办？**
A: ①拍照留证（包裹外观、破损处、内件）；②保留所有包装材料；③联系商家客服提交证据；④商家不处理可申请平台介入。注意：贵重物品建议拍开箱视频。

**Q: "您的包裹已签收"但我没收到？**
A: ①先确认是不是家人/前台/快递柜代收了；②快递柜/驿站→查看取件码短信；③以上都不是→联系快递员确认送达位置；④找不到→联系商家发起的物流投诉。

**Q: 代收点（菜鸟驿站/快递柜）能拒收吗？**
A: 放在代收点的包裹可以不去取，超过存放期限会自动退回。但建议主动联系代收点拒收或联系商家说明，避免产生超时费用。

## 运费

**Q: 运费多少钱？**
A: 商品页面标注"包邮"为免运费，"不包邮"会在结算页显示运费。运费一般6-15元（普通快递），大件按体积计算。偏远地区可能有额外运费。

**Q: 退货运费谁出？**
A: 质量问题→商家承担。非质量问题（不喜欢/不想要）→买家承担。有运费险的话可报销首重运费（一般8-15元）。

**Q: 运费险是什么？**
A: 淘宝的退货运费险和京东的退换无忧，购买后如产生退货，保险公司赔付首重运费。费用一般0.5-5元/单，由买家或商家购买。

## 收货

**Q: 确认收货前要注意什么？**
A: 检查包装是否完整→开箱检查商品是否与描述一致→试用/试穿确认功能→有无质量问题。确认无误后再点"确认收货"，确认后款项打给商家。

**Q: 系统自动确认收货是多久？**
A: 淘宝/天猫：发货后10天（虚拟商品3天）。京东：发货后20天（自营商品7天）。拼多多：发货后15天。期限内未手动确认，系统自动确认。

**Q: 收到的是别人的包裹/发错货了？**
A: 拍照联系商家客服→商家核实后安排补发或退款→错发商品一般归买家所有（或按商家要求退回，运费由商家承担）。
