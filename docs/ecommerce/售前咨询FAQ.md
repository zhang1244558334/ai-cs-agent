# 售前咨询FAQ

## 商品咨询

**Q: 这个商品有货吗？**
A: 能拍就是有货。缺货会显示"无货"或"已下架"。部分商品有地区库存差异，切换收货地址可查看。

**Q: 实物和图片有色差吗？**
A: 商品图片为实物拍摄，但因显示器/手机屏幕差异，可能存在轻微色差。对颜色敏感的买家可要求客服发自然光实拍图。

**Q: 有没有优惠？**
A: 商品页面当前价格即为实际售价（已含所有优惠）。可关注店铺首页有无优惠券可领。大促期间（618/双11/双12）会有平台满减和红包。

**Q: 什么时候有活动？**
A: 主要大促节点：618（6月）、双11（11月）、双12（12月）、年货节（1月）、三八女王节（3月）、618预热（5月底）。急用的没必要等大促。

## 商品详情

**Q: 材质/成分是什么？**
A: 请查看商品详情页"产品参数"栏，有详细的材质/成分/规格说明。如仍有疑问可咨询客服。

**Q: 尺寸/规格怎么选？**
A: 服饰类查看商品页尺码表，结合自己身体数据选择。电子产品按需求选择配置（存储/颜色等）。不确定的可提供身高体重/使用场景让客服推荐。

**Q: 包装里包含什么？**
A: 商品详情页有"包装清单"说明。标准配件在"规格参数"中列明。如需确认具体配件可咨询客服。

**Q: 产地是哪里？**
A: 商品详情页有标注产地/品牌地。进口商品标注"原产国"。

## 价格与优惠

**Q: 这个价格还能便宜吗？**
A: 标价即为当前售价。大件/高价商品可能有议价空间（部分店铺）。天猫旗舰店/京东自营一般不议价，但可关注优惠券和满减。

**Q: 为什么比XXX平台贵/便宜？**
A: 不同平台/不同店铺定价策略不同。同品牌在天猫和京东可能价格有差异（平台活动、物流成本不同）。建议综合比较后再下单。

**Q: 有赠品吗？**
A: 商品页面有"赠品"标签或"买就送"提示即有赠品。赠品一般为配件/小样/试用装，数量有限送完即止。

## 配送与时效

**Q: 发什么快递？**
A: 默认快递在商品页面标注。普通商品发中通/圆通/韵达/申通等为主。大件走德邦/安能。有特殊需求可备注或联系客服。

**Q: 多久能到？**
A: 发货时效+物流时效。一般地区发货后2-5天到。京东自营次日达/211限时达覆盖主要城市。偏远地区（新疆/西藏/青海）可能需5-7天。

**Q: 可以指定快递吗？**
A: 部分商家支持指定快递（备注或联系客服）。指定顺丰等高价快递可能需补运费差价。

## 售后保障

**Q: 支持7天无理由退货吗？**
A: 大部分商品支持（商品页面有"7天无理由"标识）。特殊商品（内衣、生鲜、定制、已激活电子产品等）不支持。

**Q: 保修多久？**
A: 国家三包规定：电子产品1年起、大家电3年。部分品牌提供延长保修。商品详情页有"售后保障"说明。
