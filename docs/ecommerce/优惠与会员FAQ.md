# 优惠与会员FAQ

## 会员体系

### 淘宝88VIP

**Q: 88VIP是什么？怎么开通？**
A: 淘宝88VIP是阿里巴巴推出的付费会员体系，年费88元（淘气值1000分以上）或888元（淘气值不足）。权益包括：①天猫超市/天猫国际/淘宝心选等全年9.5折；②优酷VIP年卡；③饿了么超级会员年卡；④网易云音乐VIP年卡；⑤淘票票每月2张立减券。开通方式：淘宝App→我的淘宝→88VIP→立即开通。

**Q: 88VIP的折扣可以和其他优惠叠加吗？**
A: 88VIP的9.5折与优惠券、满减可叠加，但部分特殊商品（如大促秒杀品、虚拟商品）不参与。具体以商品页"88VIP专享价"标识为准。

**Q: 淘气值怎么提升？**
A: 淘气值由四部分构成：①购物行为（40%）——购买频次和金额；②评价互动（30%）——评价质量与晒单；③信用记录（20%）——是否按时付款/有无纠纷；④账户信息完善度（10%）。多买多评、发优质评价（带图带视频）、按时付款可快速提升。

### 京东PLUS会员

**Q: 京东PLUS会员多少钱？有什么权益？**
A: 京东PLUS会员年费99元。核心权益：①每月5张运费券（自营免运费）；②百万商品PLUS专享价；③10倍京豆回馈（购物返10倍京豆，普通用户2倍）；④每月100元全品类券包；⑤品牌VIP折扣；⑥PLUS会员日专属折扣；⑦免费电子书。开通：京东App→我的→PLUS会员。

**Q: PLUS会员的运费券用完了还能免运费吗？**
A: 运费券用完后，自营商品不满99元需支付基础运费（一般6-8元）。PLUS会员每月自动发放5张运费券，次月重新发放，不累计。

**Q: PLUS会员的10倍京豆是什么意思？**
A: 普通用户买100元返2元京豆（2%），PLUS会员返10%（即20元京豆）。京豆100个=1元，可在下次购物时抵扣。

### 京享值（京东）

**Q: 京享值怎么计算？有什么用？**
A: 京享值由消费分+活跃分+信用分+贡献分组成。高京享值可享受运费券增加、优先客服、专属优惠等。每月1日更新。

### 拼多多省钱月卡

**Q: 拼多多省钱月卡值得买吗？**
A: 月费10-15元。权益：①每日一张全场通用券（满减/折扣券）；②免费试用机会；③月卡专享价格；④好友免费助力。经常在拼多多购物的用户划算，偶尔买的不用开。

## 优惠券

**Q: 店铺优惠券和平台优惠券有什么区别？**
A: 店铺券：只能在该店铺使用，由店铺自己发放。平台券：全平台通用（如天猫津贴、京东全品类券），由平台发放。两者可叠加使用。

**Q: 优惠券为什么用不了？**
A: 常见原因：①不满足使用门槛（如满300减30需满300元）；②指定品类/商品才可用；③已过期；④与其他优惠互斥（按最优方案计算）；⑤每人限领/限用一张。

**Q: 满减活动怎么凑单最省钱？**
A: 先加购物车看总价，不足门槛再加小额商品凑单。凑单后不满意的商品可在收货后单独退（但不建议频繁操作，可能触发风控）。

## 大促活动

**Q: 618/双11的优惠规则是什么？**
A: 大促优惠一般多层叠加：①平台满减（如跨店满300减50），这是最基础的；②店铺优惠券；③品类券（如美妆满200减20）；④红包（签到/游戏/直播间领取）；⑤88VIP/PLUS会员折扣。最终实付=商品原价-满减-优惠券-品类券-红包-会员折扣。

**Q: 预售商品付定金和全款有什么区别？**
A: 预售一般比现货便宜，定金膨胀（如付50抵100）。但定金一经支付不退不换（除非支付尾款后全额退款）。大件商品/热销品建议预售下单，小额商品无所谓。

**Q: 价格保护是什么？买贵了能退差价吗？**
A: 京东自营商品普遍支持价保，购买后7-30天内降价可申请退差价。淘宝/天猫部分商品支持价保（商品页有"价保"标识）。申请方式：订单详情→价格保护→系统自动核算。

## 积分与权益

**Q: 淘宝金币/积分有什么用？**
A: 淘宝金币可在金币频道兑换商品或抵扣现金（100金币=1元）。积分可用于抽奖、兑换优惠券。通过签到、购物、做任务获取。

**Q: 京豆怎么获取和使用？**
A: 购物返京豆（普通用户2%，PLUS会员10%），评价晒单可额外获得。100京豆=1元，下单时直接抵扣（抵扣不超过订单金额的50%）。京豆有效期最长2年，过期清零。
