# 特殊场景FAQ

## 大促（618/双11/双12/年货节）

**Q: 大促期间价格保护规则是什么？**
A: 标有"大促价保"的商品在活动期间降价可退差价。京东自营：价保7-30天（部分商品）。淘宝/天猫：部分商品支持价保（商品页有标识）。申请入口：订单详情→价格保护，系统自动核算。注意：平台红包、品类券等不计入价保计算。

**Q: 预售商品付了定金不想要了能退吗？**
A: 定金规则：支付定金后未付尾款→定金不退。因商家原因无法完成交易→定金全额退还并赔偿同等金额。技巧：付完尾款后申请全额退款（可退回定金+尾款）。所以看好再下单，别冲动付定金。

**Q: 大促物流会慢多少？**
A: 大促期间物流明显延迟：平时48小时发货的可能延长至3-5天。京东自营/天猫超市相对保障好。建议不急用的错峰买。

**Q: 大促退款会延迟吗？**
A: 退款审核从平时的1-3天延长至3-7天。售后申请量暴增，商家和平台处理不过来。不着急的话等大促高峰过后再处理退款。

**Q: 凑单的商品可以单独退吗？**
A: 满减凑单的商品可以单独退，但需注意：退掉凑单品后如不满足满减门槛，剩余商品恢复原价。频繁凑单退款可能触发风控（尤其是小额凑单）。建议按需购买，少凑单。

**Q: 秒杀/抢购的商品没抢到怎么办？**
A: 秒杀库存有限，没抢到很正常。可以关注以下时段：天猫0点/10点/20点补货、京东10点/14点/20点补货。部分秒杀可以设置"到货提醒"。

## 跨境购物

**Q: 跨境购物的关税怎么算？**
A: 跨境电商零售进口：单次限值5000元，年度限值26000元。限值内：关税0%，增值税和消费税按70%征收（综合税率约9.1%-23.1%）。超过限值按一般贸易全额征税。

**Q: 跨境商品退换货怎么处理？**
A: 一般支持7天无理由退货。非质量问题退货运费买家承担（跨境运费较高，可能100-300元）。部分商品不支持换货（涉及清关），只能退货重拍。下单前确认尺码/规格，减少退货风险。

**Q: 跨境商品的防伪溯源信息怎么看？**
A: 带有"溯源码"或"防伪码"：扫描二维码查看商品名称、原产地、物流路径、海关清关记录。天猫国际/京东国际商品有全程溯源体系。

## 企业采购

**Q: 企业采购流程是什么？**
A: 注册企业账号→上传营业执照认证→开通企业购→选购商品→对公转账或企业网银付款→开具增值税专用发票。企业采购通常有更低的价格和专属客服。

**Q: 对公转账后多久到账？**
A: 提交订单后获取汇款识别码→网银/柜台汇款（备注栏填识别码）→到账时间1-3个工作日。超过10天未到账订单自动取消。

## 礼品卡/购物卡

**Q: 京东E卡/天猫享淘卡怎么用？**
A: 绑定到个人账户→购物时选择购物卡支付。限制：通常仅限自营或指定商品、不可与其他优惠重复叠加、有有效期（一般1-3年）。不支持退卡和提现。

**Q: 礼品卡余额能取出来吗？**
A: 不能。已绑定的购物卡不能退卡/提现，余额只能在平台消费。买卡建议按需购买，别一次买太多。
