# 投诉与纠纷处理

## 常见纠纷类型

- 发货问题：超时不发货、虚假发货、物流异常
- 商品问题：与描述不符、质量问题、假货/仿品
- 价格问题：买贵了、优惠券未生效、价格欺诈
- 售后问题：商家拒绝退货、退款拖延、商家失联
- 物流问题：丢件、破损、发错货

## 处理流程

### 第一步：联系商家

先在订单详情→联系卖家，说明问题并上传凭证（照片、聊天记录等）。大部分问题商家都会处理。给商家48小时处理时间。

### 第二步：申请售后

商家未处理或协商不成，在订单详情→申请售后/退款/退货。选择退款原因，上传证据，提交后等待商家审核。商家48小时内不处理，系统自动同意退款。

### 第三步：平台介入

商家拒绝且协商失败→申请平台介入：
- **淘宝/天猫**：申请"淘宝小二"介入，小二审核双方证据后裁决
- **京东**：联系"京东客服"，上传证据，客服介入处理
- **拼多多**：申请"平台介入"，客服协调处理
- 平台介入一般1-3个工作日有结果

### 第四步：外部投诉

平台处理不满意，可进一步：
- **12315**：登录全国12315平台（www.12315.cn）投诉，需提供商家全称和订单号
- **消费保**：第三方消费投诉平台
- **黑猫投诉**：新浪旗下投诉平台
- 重大问题保留证据，可走法律途径

## 常见纠纷处理指南

**Q: 商家一直不发货，催了也没用？**
A: 超时未发货可申请"未按约定时间发货"退款，淘宝/天猫平台会判商家违约，赔付订单金额的5%-30%（最低5元）。不想要了直接退款重买。

**Q: 收到的是假货怎么维权？**
A: 保留证据（商品照片、包装、防伪码查询记录）→联系商家要求"假一赔三"或"假一赔十"→商家不认→申请平台介入，平台核实属实会判商家赔偿。京东、天猫品牌旗舰店基本没有假货问题。

**Q: 商家态度恶劣、辱骂买家？**
A: 截图聊天记录→举报该商家（店铺内有举报入口）→平台核实后会处罚商家（扣分、降权、封店）。同时可申请平台介入处理原纠纷。

**Q: 退货后商家说没收到/说东西坏了不给退款？**
A: ①提供寄回快递单号和物流截图；②如有拍寄回时的照片更有利；③申请平台介入，有快递签收记录一般都会判商家退款。

**Q: 商家跑路/关店了，还能退款吗？**
A: 申请退款→平台自动处理。平台有消费者保障基金，商家跑路了平台会垫付退款。京东自营和天猫旗舰店不存在这个问题。

## 维权建议

- 下单前看商家评分和评价（尤其是追评/差评）
- 所有沟通在平台聊天工具内进行，保留聊天记录
- 开箱拍视频，尤其是贵重物品
- 退货拍照留证（商品状况+快递面单）
- 优先选天猫旗舰店/京东自营，售后有保障
