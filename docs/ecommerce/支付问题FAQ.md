# 支付与退款FAQ

## 支付方式

### 主流支付方式

**Q: 平台支持哪些支付方式？**
A: 淘宝/天猫：支付宝（含花呗、花呗分期）、银行卡。京东：京东支付（含白条、白条分期）、微信支付、银行卡、Apple Pay。拼多多：微信支付、多多支付（含先用后付）、银行卡、支付宝（部分商品）。抖音电商：抖音支付、支付宝、微信支付、银行卡。

**Q: 花呗是什么？怎么还款？**
A: 花呗是支付宝提供的消费信贷，先消费后还款。每月1日出账，8-10日还款。按时还款无利息，分期还款有手续费。额度根据信用评估（500-50000元不等）。

**Q: 京东白条和花呗有什么区别？**
A: 白条是京东金融的消费信贷，花呗是蚂蚁集团的。白条只能在京东及部分合作商家使用，花呗支持全场景支付宝支付。白条分期费率通常略低于花呗。

**Q: 分期付款有手续费吗？**
A: 大部分平台分期有手续费（3期约2.5%、6期约4.5%、12期约7.5%，具体以页面显示为准）。大促期间常有免息分期活动（3-12期免息，平台/商家补贴手续费）。

### 支付问题

**Q: 支付时提示"风险交易"怎么办？**
A: 更换支付方式（如从银行卡换成余额），或联系银行确认卡片状态，重新尝试。多次失败可能触发风控，换绑定的银行卡或联系平台客服。

**Q: 银行卡限额怎么解决？**
A: 单笔限额通常在5000-50000元（不同银行不同）。解决方式：①分多笔支付；②用余额/余额宝支付；③调整银行App内的单笔限额；④隔日再试（有些是日累计限额）。

**Q: 支付了但订单显示"待付款"？**
A: 支付可能存在延迟，等待5-10分钟后刷新。如仍未更新，①检查银行卡/余额是否扣款成功；②扣款成功但订单未更新→联系平台客服提供扣款凭证；③未扣款→重新下单。

## 退款

**Q: 退款多久到账？**
A: 支付宝余额/花呗：即时到账。银行卡：1-3个工作日。微信支付/零钱：即时到账。信用卡：1-5个工作日（取决于发卡行）。白条：即时恢复额度。京豆/淘金币：退回账户。

**Q: 卖家拒绝了退款申请怎么办？**
A: ①先看拒绝理由，补充证据重新申请；②申请平台介入（淘宝小二/京东客服等）；③提供聊天记录等证据；④重大问题可拨打12315。

**Q: 部分退款怎么操作？**
A: 如买多件商品，只退其中一件，在退款页面修改退款金额为单件商品的金额即可。需商家同意后生效。

## 发票

**Q: 怎么开发票？**
A: 下单时在"发票信息"栏勾选，选择个人/企业，填写抬头和税号。电子发票在确认收货后自动开具（在订单详情中查看）。纸质发票随包裹寄出或单独邮寄。

**Q: 发票内容可以自己选吗？**
A: 一般默认按商品类别开（如"日用百货""电子产品"）。部分商家支持选择"明细"或"办公用品"等大类。企业发票需提供完整税号信息。

## 价格与优惠

**Q: 买完就降价了怎么办？**
A: 京东自营：订单详情→价格保护→系统自动计算差价并退款。淘宝/天猫：部分商品支持价保（商品页有标识），买贵了可申请退差价。不支持价保的商品无法退差价（可以退货重买，但需自行承担退货运费）。

**Q: 优惠券/红包用了后退款会退回吗？**
A: 优惠券/红包在有效期内退款会退回，过期则作废。京豆/淘金币/积分会退回账户。平台补贴部分退款时不退回。
