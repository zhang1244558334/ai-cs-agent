# 账号安全与隐私FAQ

## 账号安全

**Q: 账号被盗了怎么办？**
A: ①立即修改密码并解绑异常设备；②检查是否有异常订单，如有立即取消或申请退款；③联系平台客服申请账号锁定；④如账户余额或银行卡有损失，及时报警处理。

**Q: 忘记密码/无法登录怎么办？**
A: 登录页面点击"忘记密码"，通过绑定手机号/邮箱接收验证码重置。如绑定的手机/邮箱已停用，需人工申诉（提供注册信息+实名认证信息）。

**Q: 收到异常登录提醒怎么办？**
A: ①立即修改登录密码；②在安全中心解绑非本人设备；③开启双重验证（短信/人脸/指纹）；④查看近期订单是否有异常。

**Q: 怎么修改绑定的手机号？**
A: 淘宝：我的淘宝→设置→账户与安全→手机号→更换。京东：我的→设置→账户安全→手机绑定→更换。都需要原手机号接收验证码。原手机号不可用时需联系客服人工处理。

## 实名认证

**Q: 必须实名认证吗？能改吗？**
A: 根据央行规定，使用支付功能必须实名认证。上传身份证正反面完成认证。认证信息通过后一般不可修改。姓名变更需联系客服提交公安机关证明。

**Q: 未成年人的实名认证有什么限制？**
A: 16-18岁未成年人可独立实名认证。未满16岁需监护人陪同认证。未成年用户有消费额度限制（通常月累计≤5000元）。

## 隐私保护

**Q: 订单信息泄露了（有人冒充客服打电话）？**
A: 平台官方客服不会主动索要银行卡号/密码/验证码，不会引导"转账验证"。接到可疑电话立即挂断，被骗的报警+联系平台冻结账户。淘宝：开启"隐私号码保护"（快递面单隐藏真实手机号）。

**Q: 怎么隐藏我的购买记录/评价？**
A: 淘宝：我的淘宝→设置→隐私→"隐藏我的评价"。京东：我的→设置→隐私设置→"不显示购物记录"。但完全隐藏所有记录不可能——卖家/平台后端仍可查看。

## 账号异常

**Q: 账户被冻结了怎么办？**
A: 常见原因：异常登录触发风控、交易纠纷、实名信息异常、违规行为。根据提示完成验证或联系客服，一般1-3个工作日内解冻。

**Q: 账号被限制参与活动/领券？**
A: 可能是被判定为"黄牛/刷单"账号。联系客服申诉说明情况。避免频繁退货、大量使用新账号领券等行为。

## 多设备与多账号

**Q: 一个账号能在多个设备上登录吗？**
A: 淘宝/京东/拼多多都支持多设备同时登录（手机+平板+电脑），不会互踢。但登录设备过多（5台以上）可能触发风控。建议在公共设备上不勾选"记住密码"。

**Q: 两个账号可以合并吗？**
A: 所有主流平台都不支持账号合并。订单记录、余额、积分、优惠券无法转移。建议选定一个主账号使用，其他账号的资产用完后弃用。
