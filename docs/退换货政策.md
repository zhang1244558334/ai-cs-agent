# 退换货政策

## 七天无理由退换货

- 自签收之日起7天内，商品支持无理由退换货
- 退换货商品需保持完好：未拆封、未使用、不影响二次销售
- 个人贴身衣物（内衣裤、袜子等）拆封后不支持无理由退换
- 定制商品、特价清仓商品（页面标注"不支持退换"）不适用7天无理由

## 退换货条件

### 支持退换货的情况
1. 商品质量问题（破损、瑕疵、功能故障）
2. 发错商品（与下单商品不符）
3. 商品与描述严重不符
4. 七天无理由退换（满足上述条件）

### 不支持退换货的情况
1. 超过7天退换货期限
2. 商品已使用或人为损坏
3. 商品吊牌已剪、包装已拆（影响二次销售）
4. 定制/定做商品
5. 特价清仓商品（页面标注"不支持退换"）

## 退换货运费说明

| 退换原因 | 运费承担方 |
|:---------|:----------|
| 商品质量问题 | 卖家承担来回运费 |
| 发错商品 | 卖家承担来回运费 |
| 七天无理由退货 | 买家承担退货运费 |
| 七天无理由换货 | 买家承担来回运费 |
| 购买运费险 | 按保险规则赔付（一般8-12元） |

## 退换货流程

1. 联系客服 → 说明退换货原因 → 客服确认
2. 客服审核通过后提供退换货地址
3. 买家寄回商品 → 填写快递单号
4. 卖家签收检查 → 确认符合退换条件
5. 退款/换货发出
   - 退款：签收后48小时内原路返回
   - 换货：签收后48小时内发出新品

## 退款时效

| 退款类型 | 到账时间 |
|:---------|:--------|
| 原路退回（支付宝/微信） | 1-3个工作日 |
| 银行卡退回 | 3-7个工作日 |
| 余额退回 | 即时到账 |

## 质量问题举证

如因质量问题申请退换货，请提供以下任一种凭证：
- 商品破损照片/视频
- 快递面单照片
- 与客服的聊天记录截图
- 开箱视频（建议贵重商品保留）

## 售后维修

保修期内商品出现非人为损坏的性能故障，可联系客服申请售后维修。人为损坏不在保修范围内。

## 温馨提示

- 退货时请将商品、配件、赠品、吊牌一并寄回
- 建议使用有跟踪号的快递寄回，保留快递单号
- 收到退货后我们会在48小时内处理退款
- 如有疑问请联系在线客服
- 商家不处理退款时，可申请平台客服介入，超时系统自动退款

### 退货后退款异常处理

**Q: 退货后优惠券会退回吗？**
A: 如果退货后订单金额仍满足优惠券使用门槛，优惠券可退回（在有效期内可继续使用）；如果退货后订单金额不满足门槛，优惠券不退。部分退款不退还优惠券。退回后不会延长有效期。

**Q: 退款金额不对/少退了怎么办？**
A: 退款金额以您实际支付金额为准，不包括优惠券抵扣部分。如发现退款金额异常，首先核查是否扣除了运费、赠品费用或存在部分退款。如确认少退，联系客服核实退款明细。

**Q: 退货后商家不退款怎么办？**
A: 商家应在签收退货后规定时间内处理退款（一般3-5天）。如商家无故不处理：①超时系统自动达成退款协议；②申请平台客服介入，上传退货快递单号和物流签收截图；③涉及金额较大可拨打12315投诉。

### 运费险

**Q: 运费险理赔流程是什么？理赔金额怎么算？**
A: 购买运费险的商品，退货时您先垫付运费寄回，商家确认收货后系统自动发起理赔。理赔金额根据收货地址与商家地址的距离计算，一般在8-15元之间。运费险仅赔付首重运费，续重部分需自行承担。

**Q: 拒收后什么时候退款？运费怎么算？**
A: 拒收后物流退回商家，商家收到后退款。非质量问题的拒收，您可能需要承担退回运费（如有运费险可获赔付）。

**Q: 可以部分退款吗？**
A: 部分退款适用于：①商品部分有质量问题；②少发漏发；③收到商品与描述有差异但可接受。在售后申请中选择"部分退款"选项即可。

### 赠品退换

**Q: 退货时赠品要一起退吗？**
A: 退货时赠品原则上需要一并退回，如赠品已使用或丢失，商家可能从退款中扣除赠品价值。若赠品本身有质量问题，可以单独申请售后处理。

### 换货与维修

**Q: 想换货但想换不同颜色/尺码可以吗？**
A: 换货一般只能换同款同规格商品。如想换不同款式或规格，建议先退货再重新下单。如需协商请先联系客服确认。

**Q: 电器商品过了退换期，还能免费维修吗？**
A: 电器商品在保修期内出现非人为性能故障，可以享受免费维修服务。注意区分"退换期"（7天）和"保修期"（通常1-3年）：过了退换期不能退换但仍在保修期内可以免费维修。

**Q: 售后维修时间太长怎么办？**
A: 国家规定保修期内维修超过30天的，消费者可要求换货。如因维修延迟，可联系客服催促。维修超过30天，可依据国家三包规定要求换货。


## 售后补充（延保/发票/自营vs第三方）

**Q: 京东的延保服务怎么购买？保什么？**
A: 京东延保服务是自营商品质保期满后的延长保修服务。购买方式：在商品加入购物车或下单页面勾选"延长保修"服务选项，或购买后7天内联系京东客服加购。延保内容：覆盖质保期满后的非人为性能故障维修，不同品类延保时长不同（可选1-3年）。价格根据商品价格计算，一般商品售价的3%-8%。注意：延保不覆盖人为损坏、外观磨损、配件消耗品（电池、滤网等）。来源：京东帮助中心-延保服务说明。

**Q: 京东碎屏险怎么购买？理赔流程是什么？**
A: 京东碎屏险是针对手机、平板等屏幕易碎商品提供的专项保障服务。购买：在购买手机/平板时，在商品页面勾选"碎屏险"选项（一般¥99-¥199/年）。保障内容：购机后1年内，因意外摔落导致屏幕碎裂，可免费维修一次。理赔流程：联系京东客服→指定维修点检测→确认属于保障范围→免费维修。注意：碎屏险仅覆盖屏幕碎裂，不覆盖其他部件损坏（如主板、外壳等），且需在购机时或购机后7天内购买，过后不能补购。来源：京东帮助中心-碎屏保说明。

**Q: 京东上门安装服务包含哪些？怎么预约？**
A: 京东上门安装服务覆盖家电（空调、洗衣机、电视、热水器等）、家具（床、柜、桌等）、卫浴（马桶、花洒等）等品类。购买方式：在商品页面选择"送货上门+安装"套餐，或购买后通过"我的订单-安装服务"预约。安装流程：商品送达→联系京东安装客服→安装师傅上门→完成安装（大件安装一般免费，部分需收取材料费）。收费标准：基础安装免费（已含在商品价格中），额外材料费按实收取，高空作业费、打孔费等根据具体项目收费。来源：京东帮助中心-安装服务。

**Q: 京东/淘宝的以旧换新补贴怎么领取？**
A: 以旧换新流程：①在商品详情页选择"以旧换新"，填写旧机信息（品牌、型号、使用状况等）获得预估估价；②提交以旧换新订单，支付新机差价；③安排上门回收旧机（京东物流或工程师上门）；④验机后确认最终估价，多退少补。京东以旧换新补贴：部分品类（手机、电脑、家电等）有额外换新补贴（如京东补贴¥100-¥500+品牌补贴），补贴金额在商品页面有明确标注。注意：最终回收价格以验机后为准，旧机外观磕碰、功能缺失等会影响估价。来源：京东以旧换新服务页面。

**Q: 发票遗失了还能保修吗？**
A: 京东自营商品：发票遗失仍可享受保修服务。京东自营商品凭订单号即可在京东系统内查询购买记录，不需要纸质发票。第三方商家商品：需联系商家确认是否可以补开发票（部分商家支持补开，但需提供订单信息）。品牌全国联保：部分品牌要求凭发票享受免费保修，发票遗失可能无法享受品牌全国联保，但店铺保修不受影响。建议：在京东购买的自营商品，电子发票可在"我的订单-发票详情"中随时下载，不必担心遗失。来源：京东帮助中心-发票说明。

**Q: 电子发票和纸质发票有同等法律效力吗？**
A: 根据《中华人民共和国发票管理办法》及国家税务总局规定，电子发票与纸质发票具有同等法律效力。电子发票是正规的税务发票（增值税普通发票或增值税专用发票），可作为报销凭证和售后保修凭证。京东、淘宝、天猫均默认开具电子发票（下单时可选纸质发票），电子发票可在订单详情中自行下载打印。增值税专用发票需申请纸质版（用于企业进项抵扣）。来源：国家税务总局公告2020年第1号、京东帮助中心。

**Q: 京东自营和第三方卖家有什么区别？**
A: 京东自营（由京东直接采购和销售）：①商品由京东采购入仓、京东物流配送；②售后服务由京东官方负责（自营售后团队）；③发票由京东开具（京东增值税发票）；④商品质量有京东背书，正品保障更高；⑤配送时效更快（一般次日达/当日达）。第三方卖家（POP商家）：①商品由商家自己发货（可选京东物流或第三方快递）；②售后服务由商家自行负责（京东协调）；③发票由商家开具；④商品质量和商家信誉相关，需关注店铺评分和评价；⑤配送时效由商家决定。建议：重要商品、急需商品选择京东自营，普通商品可选择高评分第三方卖家。来源：京东帮助中心。

**Q: 淘宝/天猫的商家为什么有"七天放心退"和"七天无理由退换"的区别？**
A: "七天无理由退换"是根据《消费者权益保护法》第25条，消费者在网络购物中享有7日内退货的权利，无需说明理由（特殊商品除外）。"七天放心退"是部分商家主动提供的更宽松的退换政策（可能包含"过敏包退""破损包退"等专项服务）。区别：①无理由退换是法律要求（强制），放心退是商家自愿承诺；②无理由退换只覆盖部分品类（排除定制、生鲜、音像等），放心退覆盖范围由商家自定；③无理由退换需商品完好不影响二次销售，放心退条件可能更宽松。来源：天猫规则-七天无理由退换规范。

**Q: 拼多多"仅退款"政策和淘宝/京东有什么不同？**
A: 拼多多"仅退款"政策较激进：①商品价值低（一般20元以下）且物流显示异常（如虚假发货、丢件），系统可能自动触发仅退款；②商品质量问题严重（如破损、变质）且与图片严重不符，消费者可申请仅退款；③拼多多仅退款无需消费者退回商品。淘宝/京东：仅退款较少使用，仅适用以下情况：①商品破损、少发且商品价值低；②商家主动同意仅退款；③平台介入后判定仅退款。注意：拼多多仅退款政策对商家审核较严，商家可申诉。来源：拼多多商家规则-售后服务。

**Q: 包修和保修有什么区别？**
A: "包修"和"保修"在法律上有本质区别：包修（免费修）：在三包有效期内，商品出现性能故障，由商家免费维修（含更换零部件、维修工时等全部免费），消费者不需要支付任何费用。保修（可以有偿修）：商家承诺在保修期内提供维修服务，但可能收取材料费、上门费等成本费用。京东自营商品标注"全国联保"的属于包修（免费），第三方商家标注"保修"的需具体确认是否收费。建议购买时向客服确认清楚包修还是保修。来源：《部分商品修理更换退货责任规定》。

**Q: 以旧换新旧机回收后不满意价格能退回吗？**
A: 京东以旧换新：旧机回收后，如果对最终验机价格不满意（与预估价差异较大），可以选择终止回收。京东物流会免费将旧机送回。注意：旧机送回需要一定时间（一般3-5个工作日）。淘宝/天猫以旧换新：同样支持不满意退回，但需在24小时内确认最终价格，超时未确认视为同意。退机流程：联系以旧换新客服→申请终止→安排退回。建议：旧机回收前拍照留底（外观、开机状态等），如验机结果与实际情况严重不符可申诉。来源：京东以旧换新规则。

**Q: 拼多多退货包运费是什么？怎么使用？**
A: 拼多多退货包运费：是拼多多为消费者提供的退货运费保险服务，与淘宝运费险类似。符合退货包运费条件的商品，退货时系统自动补贴退货运费（一般补贴¥10-¥25元，根据地址距离计算）。使用方式：①订单页面标注"退货包运费"的，退货时先垫付运费寄回；②商家确认收货后，补贴款自动打入拼多多账户（可提现）。注意：退货包运费仅覆盖单次退货的首重运费，每月使用次数有限制（一般为3-5次/月），频繁使用可能影响该权益。来源：拼多多帮助中心-售后服务。

**Q: 家电商品的上门安装，师傅额外收费合理吗？**
A: 家电上门安装中的额外收费情况：①基础安装免费（已含在购机费用中），包括：开箱验机、安装机身、通电测试、操作讲解；②额外收费项目（明码标价，京东有统一收费标准）：打孔费（¥20-¥50/个）、加长管线费（¥10-¥30/米）、支架费（¥30-¥80/个）、高空作业费（¥100-¥300，视楼层高度）、拆旧机费（¥30-¥80/台）。提示：安装师傅上门前会出示京东统一收费标准，消费者确认后再施工。如遇乱收费，可拒绝并拨打京东客服投诉。来源：京东家电安装收费标准。

**Q: 第三方卖家发货慢，可以投诉延迟发货吗？能赔多少？**
A: 第三方卖家延迟发货投诉和处理标准：①淘宝/天猫：成交后72小时内未发货（大促期间延长），可投诉"延迟发货"，商家需支付订单金额10%的违约金（最高¥100，最低¥5）；②京东POP商家：超过承诺发货时间，消费者可投诉，商家按订单金额30%赔付（最高¥500）；③拼多多：延迟发货按订单金额1%/天赔付（最低¥3，最高¥30）。注意：定制商品、预售商品等有特殊约定发货时间的不在延迟发货范围内。来源：淘宝规则-物流管理、京东开放平台发货规则。

**Q: 商品显示"厂家全国联保"和"京东售后"有什么区别？**
A: "厂家全国联保"：商品享受品牌厂商在全国设立的官方授权维修网点提供的保修服务。消费者可凭购买凭证和保修卡，自行联系品牌售后进行维修。优势：网点遍布全国，可就近维修。"京东售后"：由京东官方提供售后维修服务。消费者只需在京东申请售后，京东安排取件、送修、送回全程服务。优势：全程一站式服务，无需消费者自行联系品牌方。注意：京东自营商品通常同时享受"厂家全国联保"+"京东售后"双重保障。来源：京东帮助中心-售后服务。

**Q: 拼多多商品"品牌黑标"是什么意思？**
A: 拼多多"品牌黑标"（黑标品牌）是拼多多平台对品牌商家的认证标识，类似于天猫的"品牌直营"标识。含义：①品牌方直接入驻或品牌方授权经销商；②商品来源可追溯，正品有保障；③享受品牌专属的售后服务和消费者保障。识别方法：商品标题下方有黑色品牌标签（类似"官方"标识）。注意：黑标品牌商品一般价格有优势（百亿补贴较多），但售后服务由品牌方或其授权方负责，与普通商家流程一致。来源：拼多多帮助中心-品牌黑标说明。

**Q: 京东商品页面显示"京东物流"和"厂家配送"有什么区别？**
A: "京东物流"配送：商品入京东仓，由京东自营物流配送，送前电话预约、配送时效有保障（一般次日达）、可上门取件退换货。配送时效：当日达/次日达/隔日达。"厂家配送"（或称厂商直送）：商品由品牌方/商家从工厂或异地仓库直接发出，使用第三方快递（顺丰、德邦等），配送时长较长（一般3-7天）。区别汇总：①时效：京东物流更快；②服务：京东物流支持改约配送时间；③售后取件：京东物流可上门取退，厂家配送需自行寄回。来源：京东帮助中心-配送方式。

**Q: 洗衣机的上门安装需要提前准备什么？**
A: 洗衣机上门安装的准备工作：①安装位置确认——预留电源插座（10A三孔）、进水口（4分水龙头或洗衣机专用水龙头）、排水口（地漏或排水管）；②拆除包装——洗衣机运输螺栓（背部的4-6颗运输固定螺栓，首次使用必须拆除，否则机身剧烈震动）；③清理安装区域——保持地面平整、清洁；④如无需打孔或特别改造，以上准备做好后安装师傅30分钟内即可完成安装。来源：京东家电安装服务说明。

**Q: 空调安装加长铜管怎么收费？**
A: 空调安装铜管加长的收费标准（京东统一标准）：①1匹/1.5匹空调：加长铜管¥80-¥100/米（含保温管、电源线、信号线）；②2匹空调：¥100-¥120/米；③3匹及以上：¥120-¥150/米。标准铜管长度：一般挂机标配3米、柜机标配4米（不足标准长度不能减费）。一般家庭安装加长1-3米较常见。注意：加长铜管焊接质量很重要，建议要求安装师傅做好保温包扎和抽真空（R32制冷剂必须抽真空15分钟以上）。来源：京东家电安装收费标准。

**Q: 淘宝"全球购"商品和天猫国际商品有什么区别？**
A: 淘宝"全球购"和天猫国际的区别：①商家性质：全球购是淘宝C店（个人/个体工商户），天猫国际是B2C平台（海外品牌或授权代理商）。②商品保障：天猫国际商品经过平台审核备案，有"正品保障"和"假一赔十"，全球购商品质量需买家自行判断。③物流：天猫国际商品从保税仓或海外仓发出，物流可全程追溯；全球购商品由商家自行安排国际物流。④关税：天猫国际商品价格已含预估税费，全球购商品可能被海关抽查缴税。⑤售后：天猫国际提供7天无理由退货（部分品类），全球购售后由商家自行决定。来源：天猫国际规则、淘宝全球购规则。
